# 2025年競輪・収集／バックテストパイプライン

このディレクトリは、本番予想APIとは独立した過去データ検証専用です。

## 固定方針

- 対象は2025年の通常ライン戦24,590レース
- 女子戦・短期・PIST6等は投入済みマニフェストで除外済み
- 収集は月別。完成済み月のRelease資産があれば再取得しない
- 発走前特徴量と結果ラベルを別テーブルへ保存
- 選手名・選手IDはモデル特徴量に使わない
- 学習期間は1〜8月、検証期間は9〜10月、最終テストは11〜12月で固定
- テスト期間を見て閾値や特徴量を調整しない
- 回収率100%未満もそのまま出力

## 実行

GitHubのActionsから `競輪2025 収集・バックテスト` を開きます。

- `collect`: 未完成の月だけ収集
- `build`: 12か月のRelease資産からCSV/SQLiteを構築
- `backtest`: 保存済みデータでPythonバックテスト
- `full`: 上記を順番に実行

成果物は `keirin-data-2025` Releaseに月別ZIP、統合データ、監査、バックテスト結果として保存されます。
